# PARA NONNA Landing

Landing estatica hecha con HTML y CSS.

## Abrir localmente

Abre `index.html` directamente en el navegador o usa la extension Live Server
de VS Code.

## Estructura

- `index.html`: contenido de la pagina.
- `404.html`: pagina de error para rutas inexistentes.
- `styles.css`: diseno y version responsive.
- `assets/background/fondo-paranonna.jpg`: imagen de fondo.
- `assets/fonts/`: tipografias auto-alojadas (Playfair Display y Cormorant Garamond).
- `assets/icons/`: logo e imagotipo.
